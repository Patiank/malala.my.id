================================================================================
          PANDUAN CARA MENYALIN DAN MENJALANKAN PROYEK MALALA 
                 DI KOMPUTER LAIN SECARA LOKAL (LOCALHOST)
================================================================================

Panduan ini ditujukan bagi Anda yang ingin menyalin seluruh folder proyek MALALA 
ke komputer/laptop lain dan menjalankannya secara lokal tanpa kendala.

--------------------------------------------------------------------------------
1. TAHAP 1: CARA MENYALIN FOLDER (TIPS AGAR CEPAT DAN RINGAN)
--------------------------------------------------------------------------------
Saat menyalin folder "Malala" ke Flashdisk, Harddisk Eksternal, atau file ZIP:

A. JANGAN SALIN FOLDER BERIKUT:
   - "node_modules"   (Ukuran ratusan MB, ribuan file kecil yang memperlambat copy)
   - "dist"           (Folder hasil build, otomatis terbuat kembali nanti)

   *Catatan: Folder "node_modules" akan di-download ulang secara otomatis dan 
    bersih di komputer baru hanya dengan 1 baris perintah npm install.*

B. FOLDER & FILE YANG WAJIB DISALIN:
   - Folder "src"
   - Folder "public"
   - Folder "scripts"
   - File "package.json" dan "package-lock.json"
   - File "server.ts"
   - File "vite.config.ts"
   - File "tsconfig.json"
   - File "firebase.json" & "firestore.rules"

--------------------------------------------------------------------------------
2. TAHAP 2: PERSIAPAN DI KOMPUTER BARU (HANYA 1 KALI DI AWAL)
--------------------------------------------------------------------------------
Pastikan di komputer tujuan sudah terpasang Node.js:

1. Unduh Node.js versi LTS (rekomendasi v20.x, v22.x, atau v24.x) dari website resmi:
   https://nodejs.org/

2. Jalankan file installer Node.js (.msi), klik "Next" hingga selesai.

3. Verifikasi instalasi:
   - Tekan tombol "Windows + R", ketik "cmd", lalu tekan Enter.
   - Ketik:
     node -v
     npm -v
   - Jika muncul nomor versi (misal v20.x.x / v22.x.x), instalasi berhasil.

--------------------------------------------------------------------------------
3. TAHAP 3: MENJALANKAN PROYEK DI KOMPUTER BARU
--------------------------------------------------------------------------------

LANGKAH 1: Buka Folder Proyek di Terminal / CMD
- Buka folder proyek hasil copy di File Explorer komputer baru.
- Klik pada bar alamat (Address Bar) di bagian atas File Explorer, ketik:
  cmd
  lalu tekan Enter. Jendela Command Prompt hitam akan terbuka di lokasi folder tersebut.

LANGKAH 2: Instal Seluruh Modul / Dependensi (Hanya 1x)
- Pada jendela CMD, ketik perintah:
  npm install

- Tekan Enter dan tunggu sekitar 1 - 2 menit sampai proses unduh selesai.

LANGKAH 3: Jalankan Aplikasi Secara Lokal
- Setelah instalasi selesai, jalankan perintah:
  npm run dev

- Tunggu hingga terminal menampilkan pesan:
  Local:   http://localhost:5000/

LANGKAH 4: Buka di Browser
- Buka browser (Google Chrome, Edge, atau Firefox).
- Ketik alamat berikut di URL bar:
  http://localhost:5000
- Website Malala sudah berjalan lancar secara lokal di komputer baru!

--------------------------------------------------------------------------------
4. PERINTAH LAINNYA YANG BERGUNA
--------------------------------------------------------------------------------
- Menjalankan mode dev (live reload saat koding):
  npm run dev

- Menjalankan build produksi & Static Site Generation (SSG):
  npm run build

- Menjalankan server hasil build:
  npm run start

- Menghentikan server lokal yang sedang berjalan:
  Tekan tombol "Ctrl + C" pada jendela CMD, lalu ketik "Y" dan Enter.

--------------------------------------------------------------------------------
5. PERTANYAAN UMUM & SOLUSI KENDALA (TROUBLESHOOTING)
--------------------------------------------------------------------------------
Q1: Apakah data katalog dan gambar tetap muncul di komputer baru?
A1: YA. Selama komputer baru terhubung ke internet, konfigurasi Firebase di 
    proyek akan otomatis menarik data katalog, foto event, dan berita dari 
    database Cloud Firestore.
    Bahkan jika komputer baru sedang offline, sistem memiliki data cadangan bawaan 
    sehingga website tetap bisa dibuka.

Q2: Bagaimana cara mengaktifkan asisten AI (Uni Mala & AI Planner) secara lokal?
A2: Buat file bernama ".env" di folder utama proyek (sejajar dengan package.json), 
    lalu isi baris berikut:
    GEMINI_API_KEY=kunci_api_gemini_anda

Q3: Muncul error merah di PowerShell: "running scripts is disabled on this system"?
A3: Gunakan Command Prompt (cmd.exe) biasa, BUKAN PowerShell. Atau jika tetap 
    ingin menggunakan PowerShell, buka PowerShell sebagai Administrator dan ketik:
    Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
